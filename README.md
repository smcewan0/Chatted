# Chatted 🔐

**A privacy-focused, end-to-end encrypted desktop messaging platform.**

Chatted was a full-stack communication application I developed using **Rust, C++, and Qt**, with a focus on privacy, security, and real-time communication.

## 💻 Tech Stack

- **Backend:** Rust
- **Frontend:** C++ / Qt
- **Encryption:** Signal Protocol
- **Architecture:** Client-server

## 🚀 Features

- 🔐 End-to-end encrypted messaging
- 💬 Direct messages and group chats
- 🌐 Custom servers and communities
- 📞 Voice and video calling
- 🛡️ Screenshot protection
- 👤 Username wallet system
- ⚡ Real-time communication
